\# 该文件夹下的项目是采用遗传算法求解函数最大值问题

\# GeneticAlgorithm.py文件中保存的就是该模型的代码

\# painting.py文件中保存的是对模型运算过程产生的数据和函数本身绘制图表的函数工具

\# main.py文件中保存的是主函数，负责提供目标函数，并调用模型进行求解

\# 此外，三个photo\_version文件夹中保存的是该模型在不同完成度下的运行效果绘制

\# photo\_version\_3中的图表为该项目最终版本的运行结果

\# fitness\_contrary中保存的是模型在不同完成度下的适应度值变化趋势图
